# Objectives

- Implement a complete Python 3 path enumeration tool.
- Use only Python standard-library modules.
- Provide a clear command-line interface with validation.
- Load wordlists safely and report useful wordlist statistics.
- Generate clean URLs using URL parsing utilities rather than string concatenation.
- Support concurrency, timeouts, redirects, custom headers, recursion, and rate control.
- Detect likely false positives using a baseline random path.
- Produce JSON and CSV reports.
- Handle common user and network errors gracefully.
- Include tests and documentation suitable for academic evaluation.
