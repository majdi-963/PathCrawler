# Future Work

Possible future improvements include:

- Optional HEAD request support.
- Response body hashing for improved false-positive detection.
- Resume files for interrupted scans.
- Sitemap or Markdown exports.
- Safer authentication profile handling.
- More detailed redirect-chain reporting.
- Optional terminal colors with automatic capability detection.
- Additional integration tests for HTTPS with local test certificates.

Future work should preserve the project's ethical boundary: path enumeration only, for authorized testing only.
